▶️ 유튜브 링크 핵심 요약기
영상 제목·채널·썸네일은 실제로 가져옵니다. 자막은 YouTube가 서버 IP를 자주 막기 때문에, 자동 추출이 실패하면 아래에 자막을 붙여넣으면 같은 결과가 나옵니다.
자동 추출이 막혔을 때 여기서 붙여넣으면 같은 결과가 나옵니다
📋 자막·스크립트 붙여넣기 (자동 추출 실패 시)
  1. 유튜브에서 영상 열기 → 설명란 펼치기 → “스크립트 표시” 클릭
  2. 스크립트 전체 선택 → 복사 → 아래에 붙여넣기
  3. “스크립트 표시”가 없으면 자막이 없는 영상입니다 — 이때는 요약을 만들 수 없습니다(가짜 요약 안 만듦)
  4. 자막 파일(.srt/.vtt)이나 영상 요약 메모가 있으면 그것도 됩니다
붙여넣은 문장에서만 요약합니다. 영상에 없는 내용은 생성하지 않습니다.
