1 API 설정 (BYOK · 내 키로 쓰기)

  1. Google AI Studio(aistudio.google.com/apikey)에서 Google 계정으로 로그인 후 Create API key를 눌러 무료 키를 만듭니다.
  2. 만든 키(AIzaSy… 또는 AQ.…)를 복사합니다.
  3. 헤더의 ⚙️ API 설정을 열어 키를 붙여넣고, 모델을 고른 뒤 연결 테스트 → 저장 및 적용을 누릅니다.
  4. 상단 배지가 🟢 실시간 API로 바뀌면 준비 끝입니다. (키가 없어도 데모 모드로 화면과 양식을 익힐 수 있습니다.)
🔒 키는 이 브라우저의 localStorage에만 저장되고, 어떤 서버로도 보내지 않습니다. Google 공식 API와 브라우저가 직접 통신합니다. 공용 PC에서는 키 삭제를 눌러 주세요. 키를 남에게 보내거나 화면에 노출하지 마세요.
모델 고르기
· gemini-3.1-flash-lite — 기본. 무료 키에서도 빠르고 안정적(실측 확인)
· gemini-3.8-flash — 고품질 장문. 무료 키는 일일 한도(429)가 있어요
· gemini-3.5-flash — 균형형. 위와 동일하게 한도가 있습니다
3.8/3.5가 429(한도 초과) 또는 404(종료된 모델)이면 자동으로 3.1-flash-lite로 바꿔 생성합니다. 실패해도 글은 나옵니다.

2 카테고리 & 글 / 스레드 생성

  1. 왼쪽 무제한 카테고리 & 페르소나 OS에서 카테고리(독자·톤·추천 키워드)를 고르거나 카테고리 추가/관리로 새로 만듭니다.
  2. 핵심 키워드를 입력하고 톤·구조를 고른 뒤 ⚡ 원클릭 통합 생성을 누릅니다.
  3. 네이버 블로그 SEO 탭 — 제목 후보 5개, 본문, SEO 진단이 함께 나옵니다. 내용을 직접 다듬고 인간미 슬롯으로 내 경험을 넣으면 저품질 위험이 줄어듭니다.
  4. 스레드 탭 — A타입(정보형 본문)과 B타입(소통형 본문)을 각각 복사하고, 링크·공정위 고지문은 첫 번째 댓글 칸에 따로 붙여넣습니다. 본문에 링크를 넣지 않는 것이 도달에 유리합니다.
  5. 공정위 문구 위치는 쿠팡 링크 글에서 상단 / 하단 / 둘 다 중에 고를 수 있습니다. 쿠팡 링크가 들어간 글은 고지 문구가 사실상 필수입니다.
  6. 소재가 많으면 배치 큐 탭에 키워드를 줄 단위로 붙여넣어 최대 20개까지 순차 생성할 수 있습니다.

3 쿠팡파트너스 & 미리캔버스 주의점

  • 쿠팡파트너스 링크는 자동 생성되지 않습니다. 파트너스에서 만든 내 링크를 복사해 상품 URL 칸에 직접 붙여넣으세요. (타인 링크·단축 링크 임의 사용은 정책 위반입니다.)
  • 상품명·혜택 문구는 AI가 다듬어 주지만 가격·재고·배송 문구는 직접 확인해야 합니다. 실제로 본 내용만 쓰세요.
  • 미리캔버스 SVG는 단순 벡터 도형용입니다. 아이콘·선·면처럼 단순한 형태는 잘 변환되지만, 사진·복잡한 일러스트·그라데이션·그림자·질감은 변환 시 뭉개집니다.
  • 그래서 이 스튜디오의 뼈대 SVG는 완성 그림이 아니라 구도·비율 가이드로 쓰세요. 뼈대를 미리캔버스에 올려 위치를 잡고, 세부 묘사는 미리캔버스 도형으로 얹는 방식이 가장 깔끔합니다.
  • PNG 1024 내려받기는 투명 배경이라 그대로 얹기 좋습니다. 미리캔버스에 올릴 때 요소명·태그는 CSV 내보내기로 한 번에 관리하세요.

4 폰(폴드8)에 앱으로 설치하기

크롬(Chrome) — 오른쪽 위 점 3개(⋮) 메뉴 → 앱 설치(또는 홈 화면에 추가) → 설치. 주소창 없는 앱 화면으로 열립니다.
삼성 인터넷 — 아래 ≡ 메뉴 → 페이지 추가 → 홈 화면에 추가.
헤더에 📲 앱 설치 버튼이 보이면 그 버튼을 눌러도 됩니다(설치 가능할 때만 나타납니다).
폴드8은 외부 액정 세로·가로, 내부 액정 가로 모두 한 화면에 맞춰 보이도록 만들었습니다. 홈 화면 아이콘으로 열면 브라우저 탭 없이 독립 앱처럼 실행됩니다.
인터넷이 끊겨도 화면·저장된 데이터는 열립니다. 다만 AI 생성은 인터넷이 필요합니다.

팁: 카테고리·큐·체크리스트는 JSON 백업으로 내보내 두면 기기를 바꿔도 그대로 복원됩니다(API 키는 안전을 위해 백업에서 제외됩니다).
